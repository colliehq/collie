Privacy

Effective August 30, 2026 · notice interview-assist-v1

Collie’s open-source local core is designed to run on your computer and needs no Collie account. It has no advertising, usage analytics, or telemetry. The optional Collie Online preview uses an account only when you choose to connect it.

This website

The static collie.run pages load no analytics or tracking scripts. Your hosting provider may process ordinary request data, such as your network address, to deliver and secure the site.

“Ask Collie” website demo

Nothing is sent until you submit the form. The question and up to six recent messages from that demo are sent through a Cloudflare Pages Function to Cloudflare Workers AI. Product files and local Collie sessions are not attached.

To limit abuse, the service processes your network address through a secret-keyed one-way function to derive a new identifier each day. The raw address is not used as a Durable Object name or stored by the site code. The object stores only a number and expiry and is deleted within 48 hours. The limit is applied before an AI request is made.

The site code does not write questions or answers to R2, KV, or Durable Object content storage; its Durable Object stores only the abuse counter. Cloudflare publishes separate Workers AI data-usage information.

The app

  • Your chosen model provider: prompts and the context required for a task go to the provider you configure. With a local Ollama model, model traffic stays on your machine.
  • Optional web features: searches, page requests, and browser automation contact the sites you ask Collie to use.
  • Optional MCP discovery: Collie first matches connection needs on your device. Searching the public MCP Registry is off until one disclosed consent; it sends only generic allowlisted labels such as calendar, github, or music, not your original request, project names, paths, URLs, searches, or conversation. Public metadata is cached locally and is not a security review. Connecting an exact provider is a separate action.
  • Optional Personal intelligence: outside-AI learning is off by default and enabled with one visible consent. Browser-history access is a separate optional Chrome permission. Raw URLs, titles, paths, queries, and searches are discarded in extension memory; only local origin/time/count summaries are kept for up to 14 days and are not uploaded. Disconnecting revokes access and deletes those summaries.
  • Optional Live Copilot: every session is explicitly started and may have no initial task description. Basic app awareness keeps application names only. A separate active-interface option keeps a bounded summary of accessibility control types and labels, which may contain visible page or document text; continuous observation discards field values and does not log keys, clipboard, titles, or screenshots. Conversation mode requires participant consent and uses Collie's first-party microphone/system-audio capture. Short audio chunks are deleted after the configured speech service returns text; transcript and compact understanding may go to the providers shown in the app. Suggestions do not act by themselves. Pressing the shortcut is an explicit handoff: Collie then retains the exact foreground process, PID/window handle, window title, and bounded interface labels so a command can return to the right window. It still excludes field values, keys, clipboard, and screenshots. The shortcut's one-shot command audio is recognized by Windows locally; only recognized text goes to the configured Collie model. A handoff can start a normal task or a durable Mission, both under Collie's ordinary permission controls. Stopping clears live capture and surface authority.
  • Optional Collie Online: selected sealed project memory, policy, learned-workflow derivatives, and Mission payloads are end-to-end encrypted between your devices. The service processes the account, device, project, timing, and approximate-size metadata required to route and coordinate them. Raw activity observations, browser-history summaries, and personal events are not uploaded by this build. Any separately labeled cloud_indexed data is outside the sealed-content guarantee and requires an explicit choice.
  • Optional phone remote: hosted remote request and response contents are end-to-end encrypted. The relay handles necessary routing metadata such as room or device identifiers, request timing, and approximate message sizes.
  • Local data: settings, sessions, memory, pairing state, and recordings remain on your machine unless you choose to send or sync them elsewhere.

Your choices

You can avoid the website demo, use the local core without an account, choose a local model, leave outside-AI, Online, and other optional network features off, disconnect browser history in one click, and delete Collie’s local state under ~/.collie. See the full product privacy notes and source code.
