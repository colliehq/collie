# Collie：减少干预与 UI/UX 复验

这一轮接续 [首轮产品审计](project-audit-2026-09-06.md)，基线是 `1f5714f8`。用户明确选择：**跳过可选步骤，必要时才询问**，并授权继续使用 Claude Code 订阅进行真实实验和本地提交。日期采用 UTC；当地仍为 9 月 6 日晚。

## 产品判断

原版提示词已经能让模型在简单场景中省略可选内容，但工具返回“需要本人处理”时，执行层仍直接暂停整项任务。仅改提示词或把权限设成全部允许，都不能解决这个问题。

默认行为现在是：能自行决定的可撤销细节直接完成；受阻的可选路径记录省略原因；必要依赖没有安全替代方案时才请求用户处理。省略不会被记为已授权或已完成，也不会让已声明的必做范围消失。

## 改动

| 原来的问题 | 现在的行为 |
|---|---|
| 可选来源要求 MFA、额外同意或缺少工具，整项任务直接停下 | `skip_optional` 和可选工具边界记录省略，继续主要工作 |
| 把“不阻塞当前分支”误当成“可以省略” | 必须明确可选；存在覆盖范围时只能匹配非必做分支 |
| 两个授权或等待条件交替出现，耗尽预算 | 检查请求之间是否有实际进展；无进展时停在明确依赖上或等待定时器 |
| 重复授权导致还有独立必做工作时也暂停 | 保留请求并继续独立范围；全部依赖同一条件时才整体暂停 |
| 用户处理了要求，继续后可能再次被问 | 准确请求 ID 对应一次持久回答；回答、需求账本和状态同事务提交，重试不会重复改范围 |
| 模型描述中的年龄文字被当成已确认个人事实 | 推测仅作参考；自动使用事实要求明确的 `profile_claim` 和精确声明 |
| 审阅模式提供无法兑现的持久授权按钮 | 不再提供该模式不会使用的作用范围 |
| 本地任务需要处理，但侧栏没有提示 | “需要你”包含本地必要阻塞和恢复任务，点击直达任务 |
| 已解决授权仍显示在任务卡片里 | 界面使用服务端过滤后的待处理列表 |
| 任务控制位于冗长日志末尾 | 控制放在进度旁边；详细步骤折叠，展开状态跨轮询保留 |
| 恢复要输入技术代号，再确认一次 | 使用未预选的结果选项和已检查声明；不会自动重放不确定操作 |
| 取消任务、取消子任务、保留或忽略学习建议有重复确认 | 按钮表达一次明确操作，保留任务审计历史 |
| 语言设置晚于任务页面返回，暂停任务一直夹杂英文 | 语言载入后更新动态内容，保留补充草稿和展开状态 |

实现见 [Mission](../harness/mission.py)、[可选步骤策略](../harness/mission_intervention.py)、[服务入口](../harness/missionweb.py)、[Web UI](../harness/webui/index.html)。开源架构对照见 [8 个固定版本的源码参考](agent-harness-reference-2026-09-06.md)。

## 真实模型实验

使用已登录的 Claude Code / Claude Agent SDK，实际模型为 `claude-opus-5`，未配置 API key 路由。日志中的 API 等价费用不代表订阅实际账单。

### 多轮可选阻塞

同样的目标：先检查可选来源，再用已有事实保存本地报告。模型真实运行，来源的 MFA、额外同意和不可用结果由本地测试能力提供；没有连接真实外部账号。

| 场景 | 原版 `1f5714f8` | 改进版 |
|---|---|---|
| 可选来源需要本人 MFA | 1 次模型调用后等待用户；未保存报告 | 4 次调用，20.379 秒；报告通过独立文件检查 |
| 可选来源需要新同意 | 1 次模型调用后等待用户；未保存报告 | 4 次调用，19.676 秒；报告通过独立文件检查 |
| 可选来源不可用 | 1 次模型调用后等待用户；未保存报告 | 4 次调用，19.964 秒；报告通过独立文件检查 |

三个新版任务都只检查可选来源一次，保留省略原因，没有挂起授权请求。原版较短的耗时代表提前停止，不代表更快完成任务。

### 下一步决策与连续编码

12 个单步决策场景覆盖可选账号、MFA、购买、工具缺失、必要身份认证、必做范围、未知发送结果、中文要求和可撤销默认选择。**改进前后均为 12/12**；该组只检查下一步的方向，不能证明完整任务成功，也不能据此声称性能提升。

连续编码使用区间合并和递归配置合并两个标准库项目。每项分别走 Claude Code worker 和 Collie 原生路径，先实现，再追加兼容性要求，最后做只读追问。宿主执行项目测试，并在模型工作区之外运行独立验收；刷新后继续同一会话。完整结果和统一回归统计待本轮验证结束后补入。

这些小样本用于发现工作流问题，不是通用模型排行榜。

## UI 与证据范围

实际加载本地页面，检查首页、任务列表、新任务、设置、必要要求和恢复面板，覆盖 1380 像素桌面与 390 像素移动布局。必要要求和恢复画面使用受控状态，真实多轮任务另有记录。内置浏览器不可用，按浏览器技能排查后使用 Playwright。

专项回归覆盖 HTTP 认证、准确回答、事务回滚、重复提交、所有权、暂停保持、跨重启恢复、可选与必做范围、等待防空转，以及真实页面中的提示入口、恢复表单、轮询和语言载入竞态。

证据在 `C:\workspace\collie-product-2026-09-06\ux-round`。最初决策脚本缺少订阅调用预留，返回零 token 错误，不算有效模型测试；修正后以独立文件 `before-v2` 重跑。初次页面脚本等待 `networkidle`，被持续事件连接阻止，也保留为脚本失败。这些失败没有改写成产品成功。
