Strategy

Best for bug fixes and tasks with a clear pass/fail check — it runs N isolated attempts and keeps the one that actually passes, so reliability beats a single try. Not for building large or new files: it is N× the cost, and nothing is written unless you choose apply winner (otherwise it is preview-only). For a large feature, use Single run and let it write incrementally.
