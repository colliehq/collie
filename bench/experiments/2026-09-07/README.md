Read the [Chinese report](../../../docs/harness-benchmark-2026-09-07.md) before interpreting scores. This is **not a publishable leaderboard or SWE-bench score**. Native product and normalized adapted-loop samples answer different questions and must remain separate. The frozen product source is Collie 0.25.0 at `8577c10a33370bf84ae9cf953db64354be92a30d`.

## Inspect without model usage

From this directory, using Python 3.11+ and Git:

```powershell
python verify.py
python verify.py --regrade-primary
```

The first command verifies the bundle's SHA-256 manifest, all 90 candidate hashes, cohort counts, and baseline/gold behavior for all seven original/diagnostic task contracts. The second also reconstructs and grades all 60 primary candidates in temporary directories. Both commands run zero model requests and require no credentials, Docker, or network. Only evaluator-owned temporary directories are removed.

The original patch task's grader required a tuple despite the prompt allowing any ordered return. `tasks.json` contains the corrected grader; `patch-grader-correction.json` retains old/new hashes. The prompt, initial files and original candidates are unchanged. `results.json` preserves original statuses and scoring correction labels. A correct Collie candidate with a protocol error remains correct-but-unclean; it is not excluded as shared infrastructure failure.

## Replay new samples

Replay requires a **Windows host**, a clean detached Collie checkout at the pinned commit, the native Claude executable 2.1.221, Claude Agent SDK 0.2.136, normal Collie dependencies and an existing authorized Claude Max login. Native file-tool restrictions are not OS filesystem isolation. Agents must never receive this bundle or its hidden graders as their working directory.

`reproduce.py` refuses a dirty/wrong source commit, an existing output directory and a deadline outside the next three hours. `--prepare-only` writes scripts and a `replay-plan.json` without invoking models. Every actual replay is new data; it does not overwrite this evidence. Paid API environment overrides are stripped by the frozen controllers. Confirm available subscription allowance before a new launch. The historical account's 5-hour allowance was exhausted, so **no model replay was performed while preparing this bundle**.

Prepare a separate source checkout and a new future deadline:

```powershell
git -C C:\workspace\collie worktree add --detach C:\workspace\collie-replay-source 8577c10a33370bf84ae9cf953db64354be92a30d
$replayDeadline = (Get-Date).ToUniversalTime().AddHours(1).ToString('o')
python reproduce.py --track native --collie-repo C:\workspace\collie-replay-source --output C:\workspace\collie-replay-native --deadline-utc $replayDeadline --repetitions 3 --concurrency 10 --prepare-only
```

Review the generated plan. To actually launch it, run its generated `native_batch.py` command, or invoke `reproduce.py` without `--prepare-only` and with **another new output directory**. The native default task selection is the four complex tasks (24 attempts at three repetitions), with 900 seconds and 48 native turns/Collie physical requests per attempt. Those turn measures are not equivalent. The scripts require normal user authorization for model usage; creating this bundle grants no new future spending authority.

Dockerfiles are supplied as build references, but their complete transitive dependencies are not locked; rebuilding is **not** a byte-identical reproduction. The runtime checks package versions, and its manifest records actual image identities. Current Collie source is overlaid read-only. The bundled adapter source has content hashes rather than a complete copy of the old Git repository.

Use `--track normalized`, `--concurrency 8`, and new output directories. To match the historical 36-cell design, run these three separate batches:

| `--task-ids` | `--repetitions` |
| --- | ---: |
| `layercfg-provenance-merge-v2,local-audit-request-id-v1,local-circuit-breaker-v1` | 1 |
| `patchkit-transactional-directory-patch` | 2 |
| `nscache-stale-reads-and-snapshots,durable-inbox-lease-revision-v2` | 2 |

Each selected task/repetition runs all four harnesses. For the exploratory shell ablation, select cache and inbox, add `--collie-shell-ablation`, and use two repetitions. For the post-hoc prompt diagnostic, use `--coverage-diagnostic` with one repetition on each track. Keep these cohorts separate.

The web controller is replayed with `--track web`; it always runs two tasks × two workers × two repetitions, concurrency 4. It requires the Playwright Python package and its Chromium browser. It starts isolated local Collie servers and temporary user-state directories. It contains two code phases and a same-thread follow-up per group. The replay wrapper substitutes source/output paths without altering the task prompts.

Original design job prompts and completion timing are preserved in the local raw tree. The six copied source audits reference the separately pinned OSS trees; their static suggestions are not additional benchmark scores.
